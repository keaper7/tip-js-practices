### Задание 2

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |

| `"8" + 2` | 10 | "82" | string | `+` со строкой - конкатенация, не сложение |
| `"8" - 2` | 6 | 6 | number | `-` не умеет конкатенировать, строка приводится к числу |
| `Number("8") + 2` | 10 | 10 | number | явное преобразование через Number() |
| `"12" > "3"` | false | false | boolean | строки сравниваются посимвольно |
| `12 === "12"` | false | false | boolean | разные типы, === не приводит их |
| `Number("")` | 0 | 0 | number | пустая строка → 0 |
| `Number("text")` | ошибка | NaN | number | не ошибка выполнения, а специальное значение NaN |
| `Boolean("false")` | true | true | boolean | любая непустая строка → true |
| `typeof null` | "object" | "object" | string | историческая особенность JS |
| `typeof NaN` | undefined | "number" | string | NaN принадлежит числовому типу |

### Задание 5 — отладка через DevTools

Исходный (неисправленный) вывод:


| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `completedTotal` = `"32"` (строка), `Выполнено: 32` вместо `5` | `completedText + additionalText` — обе переменные строки, `+` их склеивает, а не складывает | Обернуть оба значения в `Number(...)` перед сложением | `Выполнено: 5` |
| Граница цикла | `controlSum` = `6` вместо `10` | Условие `taskNumber < 4` останавливает цикл на `taskNumber = 3`, четвёртая итерация не выполняется | Заменить условие на `taskNumber <= 4` | `Контрольная сумма: 10` |

Точка останова на строке 7 (`const completedTotal = completedText + additionalText;`) показала в Scope, что `completedText` и `additionalText` — типа `string` до сложения; после Step over переменная `completedTotal` приняла значение `"32"` (строка), что подтвердило причину ошибки. Скриншот: `screenshots/debug-breakpoint.png`.

**Итоговый (исправленный) вывод:**
